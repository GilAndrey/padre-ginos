# Projeto de Estudo: Desenvolvimento com React Moderno

Este repositório é um projeto prático que demonstra a criação de aplicações web com **React**, focado nas funcionalidades mais modernas das versões **18 e 19**.

-----

### 📚 Conceitos e Ferramentas

  * **Fundamentos do React**: Construção de interfaces com JSX e utilização de Hooks, Portals e manipulação de eventos.
  * **Gerenciamento de Dados**: Gerenciamento de estado do servidor com **Tanstack Query** e roteamento com **Tanstack Router**.
  * **Performance e Otimização**: Implementação de funcionalidades do React 19 como **Actions**, **Suspense** e otimizações de performance com o **React Compiler**.
  * **Testes**: Habilidade em escrever testes unitários e testes de navegador com **Playwright**.
  * **Ferramentas de Desenvolvimento**: Configuração de ambientes com **Vite**, **ESLint** e **Prettier** para garantir a qualidade do código.

-----

### 💻 Como Iniciar

1.  Clone este repositório:
    ```bash
    git clone https://github.com/GilAndrey/padre-ginos
    ```
2.  Instale as dependências:
    ```bash
    npm install
    ```
3.  Inicie a aplicação:
    ```bash
    npm run dev
    ```
4.  Inicie a aplicação na pasta API:
    ```bash
    npm run dev
    ```
